رفع ANJIZ من الهاتف
1. استخرجي ملف ZIP.
2. افتحي مستودع GitHub المطلوب ثم Add file → Upload files.
3. ارفعي محتويات مجلد ANJIZ وليس ملف ZIP وحده. يجب أن يظهر index.html في جذر المستودع.
4. اضغطي Commit changes.
5. Settings → Pages → Deploy from a branch → main → /(root) → Save.
6. انتظري رابط Pages ثم افتحيه. هذه النسخة واجهة أمامية؛ راجعي README لمعرفة ما يحتاج إلى خادم خارجي.
