تعليمات رفع ANJIZ من هاتف Android

1) نزّلي ملف ZIP ثم افتحيه في تطبيق الملفات واختاري «استخراج».
2) افتحي GitHub ثم المستودع: mouzianzwawiya-art/anjiz-test.
3) اختاري Add file ثم Upload files.
4) ارفعي الملفات الموجودة داخل المجلد المستخرج مباشرة إلى جذر المستودع، وليس المجلد الخارجي نفسه.
5) تأكدي من رفع مجلد assets كاملًا، لأنه يحتوي على الأيقونة وصورة المكتب.
6) استبدلي الملفات: index.html وstyles.css وapp.js وmanifest.webmanifest وsw.js، وأضيفي الملفات الموجودة في assets. اتركي أي ملفات شعار أخرى تريدين الحفاظ عليها.
7) اكتبي رسالة مثل: Update ANJIZ app ثم اختاري Commit changes.
8) انتظري نشر GitHub Pages ثم افتحي:
https://mouzianzwawiya-art.github.io/anjiz-test/
9) إذا ظهرت النسخة القديمة، أعيدي التحميل أو افتحي الرابط في نافذة خاصة؛ قد تكون ملفات قديمة مخزنة مؤقتًا.

مهم:
- المشاريع والمراجع محفوظة محليًا في المتصفح ولا تنتقل تلقائيًا إلى جهاز آخر.
- تسجيل الدخول الحقيقي والمساعد الذكي والدفع غير مفعّلة حتى إعداد خدمات خارجية آمنة.
- لا تضعي كلمات مرور أو مفاتيح API سرية في ملفات GitHub العامة.
