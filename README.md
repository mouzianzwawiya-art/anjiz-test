# ANJIZ | أَنْجِز

**الشعار الرسمي:** منصتك لإنجاز أعمالك الأكاديمية والمكتبية

نسخة ويب متجاوبة (HTML/CSS/JavaScript) مبنية لتعمل داخل مستودع GitHub Pages باسم `anjiz-test`، مع شاشة افتتاحية، صفحة ترحيب تستخدم الصور التي أرسلتِها، تنقل مستقل، مشاريع ومحرر نص محلي، مراجع، أدوات نصية، إعدادات اللغة والمظهر، ودعم PWA.

## محتويات الحزمة

- `index.html` — هيكل الواجهة والنوافذ.
- `styles.css` — التصميم المتجاوب، RTL/LTR، الوضع الفاتح والداكن.
- `app.js` — التنقل والوظائف المحلية.
- `manifest.webmanifest` و`sw.js` — إعدادات التثبيت والتخزين المؤقت.
- `assets/anjiz-icon.png` — الأيقونة المعتمدة التي أرسلتِها، مقصوصة من الحواف البيضاء الخارجية لتناسب عرض التطبيق.
- `assets/icon-192.png` و`assets/icon-512.png` — نسخ PWA من الأيقونة نفسها.
- `assets/anjiz-icon-original.jpg` — نسخة الصورة الأصلية كما وصلت.
- `assets/anjiz-icon.svg` — ملف الأيقونة SVG الموجود في نسخة المشروع السابقة، محفوظ دون حذف.
- `assets/welcome-desk.jpg` — صورة المكتب الأصلية التي أرسلتِها.
- `UPLOAD_STEPS.txt` — تعليمات مبسطة للرفع من الهاتف.

## طريقة التجربة محليًا

يمكن فتح `index.html` للمعاينة الأساسية. بعض ميزات PWA والتخزين المؤقت لا تعمل إلا عبر HTTPS أو خادم محلي، وتعمل تلقائيًا على GitHub Pages بعد النشر.

## رفع التحديث إلى GitHub Pages من الهاتف

1. فكّي ضغط ZIP.
2. افتحي مستودع GitHub: `mouzianzwawiya-art/anjiz-test`.
3. اختاري **Add file → Upload files**.
4. ارفعي الملفات الموجودة داخل الحزمة إلى **جذر المستودع مباشرة**، مع مجلد `assets` كاملًا.
5. استبدلي `index.html` و`styles.css` و`app.js` و`manifest.webmanifest` و`sw.js`، وأضيفي/حدّثي الأصول داخل `assets`. لا تحذفي ملفات الشعار الأخرى التي تريدين الاحتفاظ بها.
6. اضغطي **Commit changes** وانتظري اكتمال GitHub Pages.
7. افتحي `https://mouzianzwawiya-art.github.io/anjiz-test/`. إذا ظهرت نسخة قديمة، أعيدي التحميل أو افتحي الموقع في نافذة خاصة؛ قد يحتفظ Service Worker بملفات مؤقتة لفترة قصيرة.

## الوظائف العاملة في هذه النسخة

- شاشة افتتاحية قصيرة، ثم صفحة ترحيب عند أول زيارة، مع خيار المتابعة كزائر.
- تنقل مستقل بين الرئيسية والخدمات والمشاريع والمراجع والمساعد والسوق والملف الشخصي.
- إنشاء المشاريع وتعديل بياناتها وفتح محررها وحفظ المحتوى تلقائيًا أثناء الكتابة، وحذفها وتصديرها TXT أو HTML.
- حفظ المشاريع والمراجع وبيانات الملف محليًا في المتصفح.
- إضافة المراجع وتعديلها وحذفها ونسخ صيغة مرجعية أولية وفق APA 7.
- أدوات محلية لعد الكلمات والحروف، وتنظيف النص، وتنظيم العناوين.
- واجهات عربية وفرنسية وإنجليزية أساسية، واتجاه RTL/LTR.
- المظهر الفاتح والداكن، وتصدير/استيراد نسخة احتياطية JSON.
- دعم PWA والتخزين المؤقت للملفات الأساسية.

## ما لا يعمل بعد ويحتاج إلى إعداد خارجي

- **تسجيل الدخول وإنشاء الحساب:** الواجهة موجودة، لكنها لا تنشئ حسابًا ولا تحفظ كلمات المرور لأن خدمة المصادقة غير مربوطة. لم يتم اختلاق تسجيل دخول تجريبي.
- **المساعد الذكي:** غير متصل بنموذج ذكاء اصطناعي. يلزم Backend آمن وربط API، ولا يجب وضع مفاتيح API في JavaScript المنشور للعامة.
- **المزامنة السحابية:** غير مفعلة؛ المشاريع والمراجع محفوظة على هذا المتصفح فقط.
- **سوق المحترفين والطلبات والدفع:** واجهة تعريفية غير مفعّلة. تتطلب قاعدة بيانات ومصادقة وخدمة دفع مناسبة.
- **DOCX/PDF وMicrosoft Office الكامل:** غير مدمجة في هذه النسخة. يمكن تصدير TXT وHTML؛ أما DOCX/PDF فيحتاج إلى مكتبة أو خدمة إضافية واختبارات تنسيق.
- **التحقق الآلي من صحة المصادر:** غير متوفر. صيغة APA مساعدة تنسيقية ويجب مراجعتها حسب دليل الجامعة.

## ملاحظات تقنية

- لا تحتاج الواجهة الأساسية إلى Backend لتفتح وتعمل محليًا.
- يستعمل CSS خط Google Fonts اختياريًا، مع خطوط نظام بديلة إذا لم يتوفر اتصال بالإنترنت.
- الحفظ المحلي لا يعادل نسخة احتياطية؛ استخدمي زر تصدير JSON لحفظ نسخة خارج المتصفح.
- لم أتمكن من فحص ملفات مستودع GitHub المنشور مباشرة من هذه الجلسة. فُحصت بنية الحزمة محليًا وصحة صياغة JavaScript ومسارات الأصول داخل المشروع. تعذّر إكمال اختبار تفاعلي عبر متصفح آلي في بيئة البناء، لذلك يجب تجربة تدفقات العمل على الهاتف قبل اعتماد النسخة نهائيًا.
