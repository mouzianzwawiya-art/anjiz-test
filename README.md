# ANJIZ | أَنْجِز
**الشعار:** منصتك لإنجاز أعمالك الأكاديمية والمكتبية

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية RTL متجاوبة مع شريط تنقل وأقسام منفصلة.
- تبديل إلى الفرنسية والإنجليزية، ومظهر داكن/فاتح.
- محررات قابلة للكتابة لقوالب المذكرة والبحث والتقرير.
- حفظ المشاريع وتعديلها وحذفها وتصديرها إلى TXT محلياً.
- أداة تنسيق مرجع، عداد كلمات، وقائمة مهام بسيطة.
- تجربة واجهة المساعد تشمل إدخال صوتي عبر متصفح داعم واختيار صورة؛ لا يوجد تحليل AI حقيقي بعد.
- PWA وملفات تخزين مؤقت للاستخدام الأساسي دون اتصال بعد أول تحميل.

## حدود مهمة
هذه نسخة Front-end تعمل دون خادم. **لا** يوجد تسجيل حساب حقيقي، OTP، مزامنة سحابية، قاعدة بيانات، مدفوعات، سوق فعلي، أو اتصال بنموذج ذكاء اصطناعي. لا تستخدمي كلمة مرور حقيقية هنا. يلزم Backend وخدمة مصادقة وخدمة AI عبر خادم آمن لتحقيق هذه الميزات. GitHub Pages يستضيف ملفات ثابتة فقط.

## النشر على GitHub Pages
ارفعي محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الجذر، ثم Settings → Pages → Deploy from a branch → `main` → `/(root)`.
